# Desafio-Target-Sistemas

Q1: você percorre todas as vendas, usa if / elif / else para descobrir a porcentagem e acumula a comissão por vendedor.
Q2: você procura o produto pelo código e altera o estoque usando + para entrada ou - para saída, registrando cada movimentação com um ID.
Q3: Exercício 3: você transforma a data digitada em uma data real, calcula quantos dias se passaram desde o vencimento e aplica valor × 0.025 × dias.

Tentei ser o mais objetivo possível, o código esta comentado também.
